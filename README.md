# SharpEdgeMarshall Tap

## How do I install these formulae?

`brew install sharpedgemarshall/tap/<formula>`

Or `brew tap sharpedgemarshall/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sharpedgemarshall/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
